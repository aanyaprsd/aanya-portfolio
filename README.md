# Aanya Prasad — Personal Portfolio

A responsive personal portfolio website built to showcase my technical
experience, projects, leadership, interests, and skills.

## Live Website

[View Portfolio](YOUR-GITHUB-PAGES-LINK)

## About the Project

I built this portfolio to create an interactive representation of my
professional and technical experience beyond a traditional resume.

The site includes dedicated pages for my experience, projects, interests,
and contact information, along with interactive components and responsive
design.

## Features

- Responsive multi-page design
- Interactive project and experience cards
- Infinite scrolling experience carousel
- Animated hover and glow effects
- Custom gradient and ambient lighting theme
- Dedicated About, Experience, Projects, and Contact pages
- Resume and social media integration
- Responsive navigation and layout
- Contact form interface

## Technologies

- HTML5
- CSS3
- JavaScript
- Git
- GitHub
- GitHub Pages
